# Namu (나무)

**로컬 Ollama를 사용하는 AI 채팅 앱.** 웹 검색은 기본적으로 꺼져 있습니다.
웹 검색을 활성화하면 검색어와 IP 주소가 선택한 검색 제공자에 전달됩니다.
원격 Ollama 주소를 설정하면 추론에 필요한 대화·첨부는 그 서버에 전달됩니다.
일반 대화(**CHAT**)는 물론, 로컬 프로젝트 폴더를 읽고 **승인을 거쳐** 코드를
고치는 작업 모드(**LOCODE**)까지 하나의 앱에서.

AI 엔진은 [Ollama](https://ollama.com)가 담당합니다. CPU 런타임을 포함해 빌드한
Inno 설치본은 엔진을 동봉합니다. 일반 Tauri 빌드·소스 사본에는 런타임이 포함되지
않을 수 있으며, 이 경우 공식 Ollama를 별도로 설치해 실행하세요.

> 이 앱은 AI 코딩 도구(OpenAI Codex, Anthropic Claude Code)를 사용해 제작되었습니다.

---

## 주요 기능

- **여러 로컬 모델** — 앱 안의 카탈로그(30여 종)에서 검색해 설치·전환·삭제. 이름을 직접 입력해 받을 수도 있음
- **스트리밍 채팅** — 마크다운·표·코드 하이라이트·수식(LaTeX 근사) 렌더링, 코드블록 복사·줄바꿈
- **파일 첨부** — 이미지(비전 모델), 텍스트/코드 파일. 붙여넣기도 지원
- **대화 관리** — 검색, 날짜별 그룹, 상단 고정, 마크다운으로 내보내기, 실수로 지워도 5초 실행취소
- **컨텍스트 게이지** — 입력창 아래에 "대략 N / 한도 토큰" 표시, 대화가 얼마나 찼는지 한눈에
- **긴 대화 자동 요약**(선택) — 오래된 메시지를 요약으로 접어 토큰 절약
- **LOCODE 작업 모드** — 폴더를 열면 AI가 코드를 읽고, 파일 수정·터미널 명령은 **diff 확인 + 승인**을 거쳐야만 실행. `.env`·키 파일 접근 차단, 변경 되돌리기, 실행 기록
- **선택형 AI 웹 검색** — Brave Search API / SearXNG JSON, 검색 전 확인 또는 자동 검색, 다단계 조사와 번호 출처, 검색·생성 취소
- **시스템 트레이** — 창을 닫아도 백그라운드 유지, 트레이 우클릭으로 완전 종료
- **키보드 단축키** — 앱에서 `?` 를 눌러 목록 확인
- 자동/라이트/다크 테마

## 설치 (Windows 10·11)

1. [최신 릴리스](../../releases/latest)에서 **`Namu-Setup-x.y.z.exe`** 를 내려받습니다.
2. 실행합니다. 관리자 권한은 필요 없고 `내 사용자 폴더\Programs\Namu` 에 설치됩니다.
3. 서명되지 않은 설치 파일이라 처음엔 파란 SmartScreen 창이 뜹니다 →
   **추가 정보 → 실행**.

> Windows 환경에 따라 [WebView2 Evergreen Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)을 별도로 설치해야 합니다. 커스텀 Inno 설치본은 WebView2를 설치하지 않습니다. 일반 Tauri NSIS 설치본은 Tauri의 런타임 설치 정책을 따릅니다.

**제거**: 설정 → 앱 → Namu → 제거. (내려받은 AI 모델은 `내 사용자 폴더\.ollama` 에
남으므로, 필요 없으면 그 폴더를 지우세요.)

## 처음 실행하기

설치된 모델이 없으면 채팅 대신 안내 화면이 나옵니다.

1. **Ollama 연결 확인** — 앱에 동봉된 엔진이 자동으로 켜집니다. 실패하면 "다시 확인".
2. **첫 모델 받기** — 용도별 추천 중 하나를 고릅니다.
   - *일반 대화*: `qwen2.5:3b` (한국어·다국어 균형, 약 1.9 GB)
   - *코딩*: `qwen2.5-coder:7b` (약 4.7 GB)
   - *저사양 PC*: `llama3.2:1b` (가장 가벼움, 약 1.3 GB)
   - *이미지 이해*: `llava:7b`
   다운로드 진행률과 남은 시간이 표시되고, 도중에 취소할 수 있습니다.

한 번 받으면 다음부터는 **인터넷 없이** 동작합니다.

## 사용법

### CHAT — 일반 대화
메시지를 입력해 대화합니다. AI 답변에 마우스를 올리면 **복사 / 다시 생성**,
내 메시지에는 **복사 / 수정 후 다시 전송** 버튼이 나옵니다.
📎 로 이미지·텍스트 파일을 붙일 수 있습니다(이미지는 비전 모델 필요).

### LOCODE — 프로젝트 작업 (데스크톱 전용)
헤더의 `CHAT | LOCODE` 로 전환한 뒤 **프로젝트 폴더**를 선택합니다.

- AI가 먼저 폴더를 훑어보고, 필요하면 작업 계획을 제시합니다.
- 파일을 만들거나 고칠 때는 **변경 내용(diff)을 보여주고 승인**을 기다립니다.
  삭제·이동은 빨간 경고와 함께 한 번 더 확인합니다.
- 테스트·빌드 명령은 프로젝트 루트를 작업 디렉터리로 지정합니다. **OS 샌드박스는
  아니며 사용자 계정의 다른 파일·네트워크·프로세스에 영향을 줄 수 있습니다.**
  직접 실행(`program`+`args`)과 셸(`command`) 모두 Windows 네이티브 승인을 받습니다.
- 되돌리기는 Rust가 보관한 원본이 있고 현재 파일이 변경 직후 상태와 일치할 때만
  가능합니다. 원본은 앱 실행 동안 메모리에 최대 32건 보관됩니다. 바이너리 삭제도
  512KB까지 바이트 단위로 복구하며, 대용량 파일과 비어 있지 않은 폴더는 변경·삭제하지 않습니다.
- `.env`, 개인 키 파일은 읽기·쓰기가 차단되고, 내용 속 비밀번호·토큰은 가려집니다.
- 하단 권한 선택은 미리보기 방식을 조절합니다. 어떤 설정에서도 최종 네이티브
  승인은 생략되지 않습니다. 문자열 위험도 분류는 안전성 보장이 아니며 모든
  명령(테스트·설치·간접 실행 포함)을 실행 전에 검토하세요.

작업에 적합한 모델은 앱이 등급으로 표시합니다(*코드 작업 권장 / LOCODE 가능 /
읽기·제안만 / CHAT 전용*). 코딩 모델(`qwen2.5-coder` 계열)을 권장합니다.

### 창 닫기 · 종료
창의 X 를 누르면 앱은 **트레이로 숨고** 백그라운드에서 계속 실행됩니다
(다시 열려면 트레이 아이콘 클릭). 실행 중 다시 켜면 새 창 대신 기존 창이 떠오릅니다.
**완전히 끄려면** 트레이 아이콘을 우클릭 → **종료** — 이때 AI 엔진도 함께 종료돼
메모리를 되돌려줍니다.

### AI 웹 검색 설정 (데스크톱)

1. 설정 → **AI 웹 검색**에서 `꺼짐` / `검색 전 확인` / `자동 검색`을 선택합니다.
2. **Brave**: [Brave Search API 대시보드](https://api-dashboard.search.brave.com/)에서
   발급받은 키를 입력하고 **검색 설정 저장**을 누릅니다. 입력란은 저장 후 비워지며,
   키와 검색 설정은 앱 로컬 데이터 폴더의 `research/settings.dpapi`에 Windows 사용자
   계정으로 암호화해 함께 저장합니다. 키는 localStorage·대화 기록에 저장하지 않습니다.
3. **SearXNG**: 직접 운영하는 서버 주소를 입력하세요. 서버의 `settings.yml`에서
   `search.formats`에 `json`이 활성화되어 있어야 합니다. 공개 인스턴스는 JSON을
   막을 수 있습니다. 내부 서버는 `http://127.0.0.1:8080`처럼 IP 주소를 직접 지정하고
   **내부 IP의 SearXNG 허용**을 선택해야 합니다. 이 예외는 해당 제공자에만 적용되며,
   `web_open`의 내부망 접근은 계속 차단됩니다.
4. 활성화 시 네이티브 창에서 전송 조건을 확인합니다. `검색 전 확인`에서는 검색어와
   제공자를 매번 승인합니다. 자동 모드의 CHAT은 검색마다 묻지 않습니다. LOCODE는
   자동 모드에서도 프로젝트 정보 유출을 줄이기 위해 검색어와 페이지 조회를 추가 확인합니다.
5. **저장한 설정으로 연결 확인**은 `Ollama official documentation`이라는 공개
   테스트 검색어를 실제 제공자에 전송합니다. 설정 저장 자체는 검색하지 않습니다.

모델이 웹 정보가 필요한지 판단하고 `web_search`를 호출합니다. 결과를 Ollama에
돌려준 뒤 최종 답변을 만들며, 필요하면 결과 URL을 `web_open`으로 추가 확인합니다.
CHAT의 도구 미지원 모델에는 `검색/답변`만 허용하는 JSON 대체 경로를 사용합니다.
LOCODE의 도구 미지원 모델은 프로젝트 읽기·제안만 가능하며 변경·명령 실행은 금지됩니다.

답변의 `[번호]`와 접이식 출처 패널에서 실제 조회된 출처·검색어·제공자를 확인하세요.
링크는 기본 브라우저로 엽니다. 중지 버튼은 검색과 모델 생성을 함께 취소합니다.
검색은 턴당 검색·페이지 조회 합계 6회, 결과 8개/호출, 전체 조사 120초와 토큰 한도를
적용합니다. 중복 검색은 해당 조사 세션에서 재사용하며, 세션 종료 시 캐시는 폐기합니다.

검색 실패(오프라인, 인증 오류, JSON 비활성화, 제공자 제한 등)는 패널에 표시되고
모델에도 미확인 결과로 전달합니다. API 키/서버 주소/JSON 설정을 확인한 뒤 다시 시도하세요.
검색을 꺼도 기존 로컬 채팅은 사용할 수 있습니다.

검색 API에는 전체 대화나 파일을 보내지 않고 모델이 만든 검색어만 보냅니다. 비밀정보
패턴·코드·긴 식별자가 포함된 검색어는 차단합니다. **탐지기는 모든 비밀정보를 알아낼 수
없으므로 민감한 질문에는 검색을 끄고, LOCODE 승인 창에서 검색어를 검토하세요.**
웹 내용은 신뢰하지 않는 참고 자료로 전달되며, 프롬프트 인젝션과 잘못된 인용을
모델 수준에서 완전히 방지한다고 보장하지 않습니다. 근거가 중요한 답변은 출처를 확인하세요.

### 저장·복구 및 안전 제한

대화와 첨부는 IndexedDB 스키마 v2에 저장합니다. 마이그레이션은 원자적으로 처리하고
기존 localStorage 원본을 남깁니다. 저장 공간 부족 시 오류를 알리며 성공으로 처리하지 않습니다.
대화의 이전 변경 기록에는 Rust 원본이 없을 수 있으며, 복구 불가능한 기록을 빈 파일로
덮어쓰지 않습니다. 앱 강제 종료·OS 장애 직전의 비동기 저장까지 보장하지는 않습니다.

파일 API는 프로젝트 경계·비밀 파일·심볼릭 링크·정션·하드 링크를 검사합니다. Windows에서는
파일 작업 중 부모 디렉터리를 고정하고, 내용 해시 충돌 검사와 임시 파일 교체를 사용합니다.
이 보호는 셸 명령을 제한하는 OS 샌드박스가 아닙니다. 명령은 최대 1개, 기본 120초/최대 600초,
출력 256KB로 제한하고 Windows Job으로 하위 프로세스를 정리합니다. LOCODE 에이전트는
최대 24회 도구 호출, 3분, 누적 32,000 추정 토큰 및 반복·실패 제한을 적용합니다.

컨텍스트 설정은 모델 한도 내에서 적용합니다. 표시 값은 추정치이며 이미지당 1,024토큰을
가정합니다. 실제 토크나이저·비전 인코더 사용량과는 다를 수 있습니다. 매우 큰 요청은
조용히 잘라 보내지 않고 중단합니다. 감사 로그는 프로젝트 외부 앱 로컬 데이터의 `audit/`에
마스킹해 보관하며, 사용자 계정에서 수정할 수 있으므로 변조 방지 로그는 아닙니다.

원인별 수정 기록은 [AUDIT.md](AUDIT.md), 실제 실행 결과와 미검증 항목은
[VALIDATION.md](VALIDATION.md), 현재 권한/도구 설계는 [LOCODE_DESIGN.md](LOCODE_DESIGN.md)를 참고하세요.

## 자주 묻는 질문

**대화 내용이 서버로 가나요?**
기본 localhost Ollama와 웹 검색 꺼짐에서는 대화 추론·저장을 로컬에서 처리합니다.
모델 다운로드에는 인터넷을 사용합니다. 검색 활성화 시 검색어를 검색 제공자에게,
원격 Ollama 설정 시 대화·첨부를 해당 추론 서버에 보냅니다.

**응답이 느려요.**
동봉된 엔진은 범용 **CPU 런타임**입니다. NVIDIA/AMD GPU 가속을 쓰려면
[공식 Ollama](https://ollama.com/download/windows)를 설치해 실행해 두세요.
Namu는 이미 켜져 있는 Ollama(`localhost:11434`)를 자동으로 사용합니다.

**모델·대화는 어디에 저장되나요?**
모델은 `내 사용자 폴더\.ollama`, 대화는 앱 내부 저장소(브라우저 IndexedDB)에
저장됩니다.

**"Ollama에 연결할 수 없습니다" 배너가 떠요.**
설정에서 Ollama 주소를 확인하거나, 공식 Ollama를 설치했다면 그게 실행 중인지
확인하세요. 트레이에서 완전 종료 후 다시 실행하면 동봉 엔진이 새로 뜹니다.

## 개발

**VS Code로 시작하기:** [빌드·실행·디버깅 안내](docs/VSCODE.md).
프로젝트 폴더를 열면 `Ctrl+Shift+B`로 디버그 빌드, `F5`로 Rust 디버깅,
**작업 실행** 메뉴에서 데스크톱 실행·웹 미리보기·테스트·릴리스 빌드를 선택할 수 있습니다.

순수 HTML/CSS/JS 프론트엔드(`src/`) + [Tauri](https://v2.tauri.app) 데스크톱 셸
(`src-tauri/`, Rust) + [Inno Setup](https://jrsoftware.org/isinfo.php) 설치 프로그램
(`setup.iss`). 프레임워크·번들러 의존성 없음.

```bash
npm ci
npm run dev          # 개발 실행 (Tauri)
```
