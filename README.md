# Namu (나무)

**내 컴퓨터에서만 도는 AI 채팅 앱.** 대화 내용이 어디로도 나가지 않습니다.
일반 대화(**CHAT**)는 물론, 로컬 프로젝트 폴더를 읽고 **승인을 거쳐** 코드를
고치는 작업 모드(**LOCODE**)까지 하나의 앱에서.

AI 엔진은 [Ollama](https://ollama.com)가 담당하며, 앱에 가벼운 CPU 런타임이
함께 들어 있어 **Ollama를 따로 설치하지 않아도** 바로 쓸 수 있습니다.

> 이 앱은 AI 코딩 도구(OpenAI Codex, Anthropic Claude Code)를 사용해 제작되었습니다.

---

## 주요 기능

- **여러 로컬 모델** — 앱 안의 카탈로그(30여 종)에서 검색해 설치·전환·삭제. 이름을 직접 입력해 받을 수도 있음
- **스트리밍 채팅** — 마크다운·표·코드 하이라이트·수식(LaTeX 근사) 렌더링, 코드블록 복사·줄바꿈
- **파일 첨부** — 이미지(비전 모델), 텍스트/코드 파일. 붙여넣기도 지원
- **대화 관리** — 검색, 날짜별 그룹, 상단 고정, 마크다운으로 내보내기, 실수로 지워도 5초 실행취소
- **컨텍스트 게이지** — 입력창 아래에 "대략 N / 한도 토큰" 표시, 대화가 얼마나 찼는지 한눈에
- **긴 대화 자동 요약**(선택) — 오래된 메시지를 요약으로 접어 토큰 절약
- **LOCODE 작업 모드** — 폴더를 열면 AI가 코드를 읽고, 파일 수정·터미널 명령은 **diff 확인 + 승인**을 거쳐야만 실행. `.env`·키 파일 접근 차단, 변경 되돌리기, 실행 기록
- **시스템 트레이** — 창을 닫아도 백그라운드 유지, 트레이 우클릭으로 완전 종료
- **키보드 단축키** — 앱에서 `?` 를 눌러 목록 확인
- 자동/라이트/다크 테마

## 설치 (Windows 10·11)

1. [최신 릴리스](../../releases/latest)에서 **`Namu-Setup-x.y.z.exe`** 를 내려받습니다.
2. 실행합니다. 관리자 권한은 필요 없고 `내 사용자 폴더\Programs\Namu` 에 설치됩니다.
3. 서명되지 않은 설치 파일이라 처음엔 파란 SmartScreen 창이 뜹니다 →
   **추가 정보 → 실행**.

> WebView2 런타임은 Windows 10(1809+)·11에 기본 내장되어 있어 따로 받을 필요가 없습니다.

**제거**: 설정 → 앱 → Namu → 제거. (내려받은 AI 모델은 `내 사용자 폴더\.ollama` 에
남으므로, 필요 없으면 그 폴더를 지우세요.)

## 처음 실행하기

설치된 모델이 없으면 채팅 대신 안내 화면이 나옵니다.

1. **Ollama 연결 확인** — 앱에 동봉된 엔진이 자동으로 켜집니다. 실패하면 "다시 확인".
2. **첫 모델 받기** — 용도별 추천 중 하나를 고릅니다.
   - *일반 대화*: `qwen2.5:3b` (한국어·다국어 균형, 약 1.9 GB)
   - *코딩*: `qwen2.5-coder:7b` (약 4.7 GB)
   - *저사양 PC*: `llama3.2:1b` (가장 가벼움, 약 1.3 GB)
   - *이미지 이해*: `llava:7b`
   다운로드 진행률과 남은 시간이 표시되고, 도중에 취소할 수 있습니다.

한 번 받으면 다음부터는 **인터넷 없이** 동작합니다.

## 사용법

### CHAT — 일반 대화
메시지를 입력해 대화합니다. AI 답변에 마우스를 올리면 **복사 / 다시 생성**,
내 메시지에는 **복사 / 수정 후 다시 전송** 버튼이 나옵니다.
📎 로 이미지·텍스트 파일을 붙일 수 있습니다(이미지는 비전 모델 필요).

### LOCODE — 프로젝트 작업 (데스크톱 전용)
헤더의 `CHAT | LOCODE` 로 전환한 뒤 **프로젝트 폴더**를 선택합니다.

- AI가 먼저 폴더를 훑어보고, 필요하면 작업 계획을 제시합니다.
- 파일을 만들거나 고칠 때는 **변경 내용(diff)을 보여주고 승인**을 기다립니다.
  삭제·이동은 빨간 경고와 함께 한 번 더 확인합니다.
- 테스트·빌드 같은 **터미널 명령**도 승인 후 프로젝트 폴더 안에서만 실행되며,
  출력·시간 제한이 걸립니다. 패키지 설치·네트워크·Git 변경은 재확인이 필요합니다.
- 모든 변경은 **되돌리기** 버튼으로 복구할 수 있고, 작업 기록이 남습니다.
- `.env`, 개인 키 파일은 읽기·쓰기가 차단되고, 내용 속 비밀번호·토큰은 가려집니다.
- 실행 권한은 하단에서 *항상 묻기 ~ 전체 허용* 중 선택. 위험 명령(`rm -rf` 등)은
  어느 설정에서도 자동 승인되지 않습니다.

작업에 적합한 모델은 앱이 등급으로 표시합니다(*코드 작업 권장 / LOCODE 가능 /
읽기·제안만 / CHAT 전용*). 코딩 모델(`qwen2.5-coder` 계열)을 권장합니다.

### 창 닫기 · 종료
창의 X 를 누르면 앱은 **트레이로 숨고** 백그라운드에서 계속 실행됩니다
(다시 열려면 트레이 아이콘 클릭). 실행 중 다시 켜면 새 창 대신 기존 창이 떠오릅니다.
**완전히 끄려면** 트레이 아이콘을 우클릭 → **종료** — 이때 AI 엔진도 함께 종료돼
메모리를 되돌려줍니다.

## 자주 묻는 질문

**대화 내용이 서버로 가나요?**
아니요. 모델 추론·대화 저장 모두 이 PC 안에서만 이뤄집니다. 인터넷은 모델을
처음 내려받을 때만 씁니다.

**응답이 느려요.**
동봉된 엔진은 범용 **CPU 런타임**입니다. NVIDIA/AMD GPU 가속을 쓰려면
[공식 Ollama](https://ollama.com/download/windows)를 설치해 실행해 두세요.
Namu는 이미 켜져 있는 Ollama(`localhost:11434`)를 자동으로 사용합니다.

**모델·대화는 어디에 저장되나요?**
모델은 `내 사용자 폴더\.ollama`, 대화는 앱 내부 저장소(브라우저 IndexedDB)에
저장됩니다.

**"Ollama에 연결할 수 없습니다" 배너가 떠요.**
설정에서 Ollama 주소를 확인하거나, 공식 Ollama를 설치했다면 그게 실행 중인지
확인하세요. 트레이에서 완전 종료 후 다시 실행하면 동봉 엔진이 새로 뜹니다.

## 개발

순수 HTML/CSS/JS 프론트엔드(`src/`) + [Tauri](https://v2.tauri.app) 데스크톱 셸
(`src-tauri/`, Rust) + [Inno Setup](https://jrsoftware.org/isinfo.php) 설치 프로그램
(`setup.iss`). 프레임워크·번들러 의존성 없음.

```bash
npm install
npm run dev          # 개발 실행 (Tauri)
node scripts/dev-server.mjs 8000   # 웹 미리보기 (Ollama가 떠 있어야 함)
node test.mjs        # 순수 함수 단위 테스트
```

**설치 프로그램 빌드** (Windows): Rust · VS C++ Build Tools · Inno Setup 6 설치 후

```bash
build.bat
```

테스트 → `tauri build --no-bundle` → `installer/payload/` 스테이징(앱 + 동봉 Ollama
CPU 런타임) → Inno Setup 컴파일 순으로 실행되어
`installer/output/Namu-Setup-<버전>.exe` 가 생성됩니다.
배포 전 `setup.iss` 상단의 `MyAppPublisher` · `MyAppURL` 을 채우세요.

```
src/
  index.html   마크업 + 스타일
  app.js       앱 로직 (상태·렌더링·채팅·모델·온보딩·모드 전환)
  lib.js       순수 헬퍼 (스트림 파싱·마크다운·토큰 추정·diff — 테스트 대상)
  locode.js    LOCODE 에이전트 루프 + 승인 UI + 파일 트리
  store.js     IndexedDB 영속 계층
  net.js       Ollama 호출 추상화 (Tauri→Rust 프록시 / 웹→직접 fetch)
  models.json  추천 모델 카탈로그
src-tauri/src/
  main.rs      Ollama 자동 실행·정리, 시스템 트레이, 단일 인스턴스
  ollama.rs    Ollama HTTP 프록시 (웹뷰 CORS 우회, 스트리밍·취소)
  locode.rs    LOCODE 안전 파일·명령 계층 (경로 격리·비밀 마스킹·감사 로그)
```

동봉 Ollama 런타임은 `src-tauri/ollama-bundle/` 에 있으며
`scripts/prepare-ollama-bundle.ps1` 로 갱신합니다.
